# AIfra uptime

External HTTPS availability checks for AIfra. No application source or credentials are stored here. Standard GitHub-hosted runner; hourly best-effort schedule, not an SLA. Configure origins and SMTP identity in repository variables, password only in UPTIME_SMTP_PASSWORD secret. Set UPTIME_ENABLED=true after testing. Public schedules may be disabled by GitHub after prolonged repository inactivity; inspect Actions regularly.
